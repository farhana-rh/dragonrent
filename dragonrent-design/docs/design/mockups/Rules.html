Easy for ages 8 to 80

  1. One main button per screen. Cobalt, full width on phones. Everything else is quieter.
  2. Easy to tap. Buttons 48–52 px tall; every tap area at least 44 px.
  3. Words with icons. The menu button says “Menu”; status tags have an icon and a word, never color alone.
  4. Plain words. Short sentences a 9-year-old understands.
  5. No price surprises. The full total shows before any button that costs money.
  6. Step by step. Long tasks become short steps marked “Step 2 of 5”.
  7. Easy to undo. Back on every step; a check screen before sending; a confirm before anything final.
  8. Visible focus. A 3 px Cobalt ring on whatever the keyboard is on.
